# Design system

## Direction

An editorial wardrobe companion: garment photographs carry the visual weight, with quiet paper-like surfaces, precise dark type, and one warm persimmon accent. The interface should feel like a considered personal wardrobe record, not an AI dashboard or a fashion marketplace.

## Tokens

| Role | Value |
| --- | --- |
| Canvas | `#F4F1EB` |
| Surface | `#FFFEFC` |
| Ink | `#252621` |
| Muted ink | `#74736B` |
| Rule | `#DDD9D0` |
| Accent | `#C65D43` |
| Soft accent | `#F4E7E1` |
| Positive | `#53694E` |

Headings use a system serif. Body text and controls use a system sans serif. Labels are compact and plain, never uppercase tracking that harms readability. Spacing follows a 4px base. Focus uses a 3px accent outline with offset.

## Interaction

The primary path is verified email/password sign-in, add one real garment, then request an outfit for an occasion. Keep wardrobe, decision, and privacy reachable from the main navigation. Never use sample garments, external trackers, fake confidence, or a button that suggests unavailable AI.
